
# Book CRUD Application — Домашнее задание по FastAPI

## Описание проекта

Веб-приложение для управления списком книг, разработанное с использованием FastAPI, SQLAlchemy, SQLite, HTML, Bootstrap и JavaScript.

Приложение позволяет:
- Добавлять новые книги
- Просматривать информацию о книге по ID
- Редактировать данные книги
- Удалять книги
- Просматривать список всех книг

## Домашнее задание

### Задание 1. Добавить форму для фильтрации таблицы

Над таблицей Books List добавлена форма поиска книг.

Реализованы следующие возможности:
- Поиск по названию книги
- Поиск по автору
- Поиск по жанру
- Поиск по ID книги
- Сброс фильтра кнопкой Reset

Фильтрация выполняется с помощью JavaScript без перезагрузки страницы.

### Задание 2. Добавить в таблицу кнопку удаления строки

В таблицу Books List добавлен столбец Actions.

Для каждой книги предусмотрена кнопка Delete.

При нажатии кнопки:
1. Появляется запрос на подтверждение удаления.
2. Отправляется DELETE-запрос к API FastAPI.
3. Книга удаляется из базы данных.
4. Таблица автоматически обновляется.

## Установка и запуск проекта

1. Склонировать репозиторий GitHub.
2. Открыть папку project в VS Code.
3. Создать виртуальное окружение:

   `python -m venv venv`

4. Активировать виртуальное окружение в Windows PowerShell:

   `.\venv\Scripts\Activate.ps1`

5. Установить зависимости:

   `python -m pip install -r requirements.txt`

6. Запустить сервер:

   `python -m uvicorn app.main:app --reload`

7. Открыть приложение в браузере:

   `http://127.0.0.1:8000/`
